## 🛠️ Local Vite + React + Tailwind Development Setup
If you want to run it via the local development server on your machine:
```bash
# 1. Install dependencies (on an unrestricted network or personal hotspot)
npm install

# 2. Start the local dev server
npm run dev

# 3. Build for production (e.g. Vercel, Netlify, GitHub Pages)
npm run build
```
